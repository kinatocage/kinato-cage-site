# 再発防止セーフティアーキテクチャ＆安全デプロイ仕様書

## 1. 概要と背景
2026年9月30日に発生した2大クリティカル事案：
1. **本番環境への資材内訳（BOM・原価情報）の漏洩**
   - 原因: 開発検証用に `index.html` に記述した静的セクションが本番デプロイ時に残存。
2. **見積もりログのサイレント不達（ログ欠損）**
   - 原因: パネル原価計算ループ内での未宣言変数（`singleCost`）による `ReferenceError`。例外によりログ送信処理まで到達せずサイレントクラッシュ。

本ドキュメントは、これらの再発を**「人為的注意に頼らず機械的・自動的に100%防止する」**ために構築された安全機構の技術仕様です。

---

## 2. 導入された3重の再発防止機構

### ① デプロイ時セーフティゲート（`npm run deploy:safe`）
デプロイコマンドを単一の安全検証パイプラインに統合（`scripts/deploy-safe.mjs`）。

```text
[開発者] npm run deploy:safe
   │
   ├─▶ [Step 1] 静的コード検証（ESLint）
   │     └─ 未宣言変数（no-undef）や構文エラーがあれば即時デプロイ停止！
   │
   ├─▶ [Step 2] ソースコードBOM静的スキャン
   │     └─ cage_mitumori/index.html にBOM関連タグがあれば即時デプロイ停止！
   │
   ├─▶ [Step 3] プロダクションビルド（build-sim & astro build）
   │     └─ ビルド失敗時は即時中止
   │
   ├─▶ [Step 4] 成果物漏洩スキャン（Dist Leak Scan）
   │     └─ public/sim/ や dist/ 内の全HTMLにBOMタグが含まれていないか検査
   │
   ├─▶ [Step 5] GASエンドポイント設定検証
   │     └─ gasLogEndpointUrl が有効なGAS URLか検査
   │
   └─▶ [Step 6] Cloudflare Pages へ本番デプロイ
```

### ② BOM（資材リスト）の動的デバッグ注入化（ローカル環境限定・本番完全遮断）
- **本番環境（完全遮断）**: `kinato-cage-site.pages.dev` 上では、URLに `?debug=bom` を付与してもセキュリティ保護判定（`isLocalDevelopmentEnvironment()`）により**絶対に生成・表示されません**。第三者による原価漏洩リスクは完全にゼロです。
- **ローカル開発環境**: 手元の開発時（`localhost` / `127.0.0.1`）のみ、URLパラメータに `?debug=bom`（または `?dev=bom`）が付与された時にJavaScriptが動的にアコーディオンDOMを生成・注入します。
- **二重安全性**: 静的HTMLに一切含まれず、かつ本番ドメインでは実行コード自体がスキップされるため、完璧な原価秘匿を実現しています。

### ③ 計算エラー・サイレントクラッシュの自動通報（`type: calc_error`）
- 見積もり計算中に予期せぬ例外エラーが発生した場合、画面に「⚠️ 計算中にエラーが発生しました」と明示表示。
- 同時に発生したエラーメッセージ・スタックトレース・寸法仕様を `type: 'calc_error'` としてGoogle Apps Scriptへ即時バックグラウンド送信。
- スプレッドシートの「エラーログ」シートにリアルタイム自動記録され、管理者が迅速に異常を検知できます。

## 3. 日常の運用手順

### 通常の開発作業
```bash
npm run dev         # Astroサイト起動
npm run build:sim   # シミュレーターのみビルド・同期
```

### 本番デプロイ時（推奨）
**必ず以下の安全デプロイコマンドを使用してください：**
```bash
npm run deploy:safe
```
もし未宣言変数やBOMの静的混入があった場合、コンソールに赤文字で警告が表示され、デプロイが自動拒否されます。

### BOM（原価内訳）の確認方法（※ローカル環境限定）
手元のローカル開発環境でのみ、ブラウザのアドレスバーでURLの末尾に `?debug=bom` を付けて開きます：
- ローカル: `http://localhost:5173/?debug=bom`（または Astro: `http://localhost:4321/sim/?debug=bom`）
- 解除: `?debug=off`
- ※本番URL（`kinato-cage-site.pages.dev`）では `?debug=bom` を付与してもセキュリティ保護により一切表示されません。
