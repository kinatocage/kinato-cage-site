# きなとのケージ屋さん 3Dケージ設計・見積もりシミュレーター

爬虫類・小動物用アルミフレームケージのオーダーメイド設計および部材見積もりを、Webブラウザ上で直感的に行える高品位3Dシミュレーターです。

---

## 🌟 主な機能と特徴

### 1. 2つのケージ基本構造
- **Type A（全面スライド扉）**:
  - 正面床フレームに「2040（1段上がり）」を採用し、開口部を最大化した全面引き違い扉モデル。
- **Type C（前窓付き）**:
  - 床面を「2020」で均一化し、下部にアクリルはめ殺し固定窓（高さ指定可能）＋上部に引き違い扉を備えた深底・床材保持モデル。

### 2. 精密パラメトリック寸法設計
- **標準初期寸法**: **W750 × D450 × H300 mm**
- **幅 (W)**: 300mm 〜 1800mm（10mm刻み）
- **奥行き (D)**: 300mm 〜 900mm（10mm刻み）
- **高さ (H)**: 200mm 〜 900mm（10mm刻み）
- **前窓高さ (Type C専用)**: 30mm 〜 (H - 120mm)（10mm刻み）
- **標準サイズにリセット**: ワンクリックで初期サイズ（750×450×300mm）および標準仕様へ復帰。

### 3. PC・スマホ両対応（レスポンシブ & カテゴリ別4タブ切り替えUI）
スマートフォン（iPhone / Android）およびPCの大画面の双方で、直感的にケージの3D確認・設定が行えるように設計されています：
- **4つのカテゴリタブ（PC・スマホ共通・均等グリッド配置）**:
  - **🦎 ① 生体サイズ**: フトアゴヒゲトカゲ、ボールパイソン、レオパ、リクガメなどの人気生体推奨寸法プリセット（ワンタップで3Dモデル・寸法スライダー・補強判定が自動連動）
  - **📐 ② 基本・寸法**: ケージタイプ（Type A / C）、フレーム色（シルバー / ブラック）、寸法（W / D / H / 前窓開口）、扉開閉テスト
  - **🧩 ③ パネル素材**: 正面扉、床面、側面（左右・2分割）、背面、天面（パンチング・金網3種・2分割）
  - **⚙️ ④ オプション**: 幅広フレーム（2倍幅 / 3倍幅）、側面補強、側面換気板、床・天板補強、たわみ防止レール、キャスター仕様
- **スマホ専用レイアウト（900px以下 / 420px以下 自動切替）**:
  - **上下分割配置**: 上部（約43vh）に3Dビューア、下部にタブ式コントロールパネルを配置。
  - **3Dオーバーレイの重なり解消**: 左上の見積もりHUDカードのスリム化、右上の視点ボタンの横スクロール・アイコン化により、狭い画面幅（375px〜400px）でも重ならず綺麗に収まるレイアウト。
  - **超コンパクトUI**: ケージタイプカードやフレーム色ボタンを横並び2列のセグメントボタン型にスリム化し、縦スクロール長を最小化。
  - **下部固定フッター（スティッキーバー）**: どのタブを開いていても画面最下部に「見積もり・重量計算ボタン」と「標準リセットボタン」が常駐し、いつでもワンタップで計算可能。
  - **操作ガイド自動切り替え**: スマホ時は「1本指で回転 / 2本指ピンチでズーム」のガイドに自動切替。

### 4. スマホ向け縦型「見積もり結果カード」画像保存 ＆ 仕様コピー機能
- **高解像度 縦型9:16（1080 × 1920px）PNGカード生成**:
  - 見積もり計算後、「見積もりカードを画像保存 (PNG)」ボタンを押すことで、現在の3Dパース・設計パラメータ・合計金額をCanvas合成したスタイリッシュな画像カードを端末へダウンロード・保存。
  - **📱 スマホ（iPhone / Android）写真アプリ保存対応**:
    - **Web Share API (`navigator.share`)**: iPhone（iOS Safari）では共有メニューが開き、「画像を保存」をワンタップするだけで端末の**「写真（カメラロール）」アプリに直接保存**されます。Androidでも「フォトに保存」「端末に保存」等を直接選択可能。
    - **長押し保存用インラインプレビュー**: 共有メニューを閉じた場合でも、モーダル内に生成されたカードのプレビュー画像が表示されるため、**「画像を長押し ➜ 『"写真"に追加』」** でも確実に保存できます。
    - **PC**: 従来通りブラウザの「ダウンロード」フォルダへ直接PNGファイルが保存されます。
  - **ヘッダー部**: 「きなとのケージ屋さん」公式ロゴ、ショップURL（`https://kinato-cage-site.pages.dev/`）、**真ん中にショップアイコンが入った高精細QRコード**、一意の見積ID、発行日時を印字。
  - **スペック部**: ケージ種類、外寸サイズ、フレーム色（シルバー/ブラック）、**選択されているすべての面のパネル素材・板厚**（正面扉、前窓、床面、背面、側面、天面）、**選択されているすべてのオプション**（チェックマーク付き）を完全網羅。
  - **プライス＆キャラクター部**: 概算総重量、お見積もり合計金額（税込）、および公式キャラクター（透過PNG）をレイアウト。
- **お問い合わせ仕様テキストのワンタップコピー**:
  - 見積IDや選択仕様が整理されたテキストをモーダル内に自動生成。「コピー」ボタンでクリップボードへ保存でき、LINE・メール・SNSでの問い合わせにそのまま活用可能。
メニュー内の並び順を用途・設計思想に合わせて最適化しています：
1. **正面下側幅広フレーム（2倍幅 / 3倍幅）**:
   - **正面下側幅広フレーム2倍幅**（Type A 初期値: **ON**）:
     - 床正面に高さ40mmフレームを使用し、床材厚みを隠して剛性を向上（Type A専用）。
   - **正面下側幅広フレーム3倍幅**（Type A 初期値: **OFF・非活性**）:
     - 床正面に高さ60mmフレームを使用し、深床材飼育や高剛性に対応（Type A専用）。
     - **シルバーフレーム**: 3スロットの `AFS-2060-4`（1本）を使用。
     - **ブラックフレーム**: AFS-2060が存在しないため、40mm幅フレームの上に20mm幅フレームを乗せる**2段重ね構成（計2本使用、BOMも2部材集計）**を再現。
   - **排他制御**:
     - 2倍幅ON時は3倍幅が選択不可（非活性・disabled）。
     - 3倍幅ON時は2倍幅が外れて選択不可（非活性・disabled）。
     - 両方OFF時はどちらも選択可能（正面下側フレームは標準の高さ20mm・2020フレーム）。
     - Type C選択時は前窓構造のため両オプションとも選択不可（非活性）に制御。
   - **扉・ガラスレール連動**: フレーム高さ（標準: 20mm / 2倍幅: 40mm / 3倍幅: 60mm）に連動して、下側ガラスレール取付高さ、引き違いスライド扉の高さ、扉たわみ防止レールの長さが自動調整されます。
2. **側面補強フレーム**:
   - 左右対称の補強構造。側面上部（パンチング部）開口高さを任意指定可能（mm単位）。
   - 設定可能範囲: 最小50mm 〜 最大 (H - 110)mm（どちらかのパネル間口高さが50mmを下回るまで調整可能）。ケージ全高に応じて半分より大きい数値もスムーズに設定可能。
   - 上部パンチング・下部アクリルなどの分割パネル構成や側面換気量調整板、3D寸法線ラベル（側面上部開口）と完全連動。
3. **側面換気量調整板**:
   - 側面上部パンチングパネルの外側に透明アクリル（t1.5）板を配置し、No.1化粧つまみネジ（計8箇所、M4手締め・工具不要）で固定。冬場の保温や換気量調整に対応（側面2分割時のみ選択可能）。
4. **床面中央補強フレーム**:
   - **床面積連動判定**: 床面積が標準 750×450mm（337,500 mm²）を超える場合に初期ON・推奨。
   - **幅 940mm 超の必須化**: 幅が 940mm を超えた場合は構造強度維持のため自動的に必須適用（解除不可）。
   - 推奨サイズでチェックを外した場合は「⚠️ 床面アクリルがたわみやすいので、床面中央補強フレームを推奨します」の注意喚起バナーが表示されます。
5. **天板中央補強フレーム**:
   - 幅 W > 940mm の場合は自動的に必須適用（解除不可）。幅を 940mm 以下に戻した際は自動的にOFFへ復帰。
   - 天面が2分割の場合、左右個別にパネル素材（金網、塩ビパンチング、透明アクリル）を選択可能。
6. **正面スライド扉 たわみ防止レール**:
   - 大型・強力爬虫類向け仕様。左右端の柱内側に下側ガラスレール（PGRL-03-4）を縦向きに追加し、扉の押し出し変形を防止（扉幅を-2mm自動調整）。
7. **キャスター仕様**:
   - **OFF時（標準）**: **ゴム脚 (H11mm)** を底面4隅に自動装着。
   - **ON時（オプション）**: **自在キャスター (車輪径φ50 / 取付高66mm)** を装着。床グリッド面もキャスター接地レベルに自動追従。
8. **止まり木（天板吊り下げ式・後付け対応）**:
   - **概要**: 天板パンチングパネルの穴（φ3.1-P7）を利用し、M3x8つまみネジ（計4箇所）で固定するφ30mmアルミ丸棒（ASTP-30）止まり木。納品後の後付けも可能。
   - **構成部材**:
     - 天板固定フレーム: `AFSF-2020-4`（長さ90mm、室内側溝なし面下面向き、両端にECP-2020-4-GY）× 2本
     - 垂直吊り下げフレーム: `AFS-1530-6`（長さ H/2、下端にECP-1530-6）× 2本
     - 止まり木本体: `ASTP-30`（φ30アルミパイプ）× 1本
   - **寸法・穴ピッチ整合**:
     - 丸棒長さは天板パンチング穴ピッチ7mmに合わせ、中央間距離 $D_{center} = \lfloor(W - 120) / 7\rfloor \times 7$、丸棒長 $L = D_{center} - 15$ mm として自動整合。
     - 垂直フレームには下端から15mm位置を含む3箇所の高さ調整用穴（10mm単位ピッチ）を加工。3Dプレビューでは中央穴位置に丸棒を配置。
   - **天面連動**: 止まり木ON時に天面が塩ビパンチングでない場合、自動的に塩ビパンチングへ切り替え、案内トースト通知を表示。
   - **価格計算**: 止まり木資材費（実費原価×1.5倍・100円単位切り上げ）＋ 加工工賃1,000円。
   - **カラー対応**: シルバー・ブラックフレームの両方で選択可能（止まり木部材はシルバー仕様）。
9. **２室分け（後付け仕切り板・Type A/C両対応）**:
   - **概要**: 成長に応じたケージ幅の調整や多頭飼育・隔離に対応する、後付け可能な中央仕切り板オプション。
   - **構造・金物仕様**:
     - **ブラケット**: 正面フレーム室内側の上段溝にL字ブラケット（`ABL-2015-4`、シルバー）を取り付け、正面フレーム垂直面にボルト固定。仕切り板側面から白いM3化粧つまみネジで横締め固定。
     - **天面固定**: 天板パンチングパネルの穴を利用し、仕切り板を挟み込むように互い違いに配置したM3つまみネジ（計4本）で転倒を防止。
     - **寸法・切り欠きノウハウ**: 正面側下端（コーキング逃げ 18×18mm C面）、正面側上端（直角角）、背面側上端・下端（フレーム逃げ 18×18mm C面）を精密加工。
     - **排他制御**: 止まり木オプションと相互排他制御（どちらか一方がONの場合、他方は非活性/disabled）。
     - **天面注意事項**: 天面が金網等の場合でもプレビューは可能とし、「天板は塩ビパンチングパネル仕様前提でのオプションとなっています。金網での実装方法の詳細はDMにてお問い合わせください」とトーストで案内。
     - **価格計算**: 資材費（仕切り板＋ABL-2015-4金具）×1.5倍（100円単位切り上げ）＋加工工賃500円。
     - **表示配慮**: パネル選択肢やモーダル見積もり上で、仕切り板のミリ寸法はお客様画面に非表示（製造ノウハウ保護）。

### 4. パネル詳細設定（アコーディオンUI）
パネル種類の設定順序を使いやすく整理しています：
1. **正面**: 透明アクリル (t3) 固定。
2. **床面**: **透明アクリル (t3)** または **ブラックマット地アクリル (t3)** を選択可能（補強の有無により1枚または2分割）。
3. **側面**:
   - 補強なし時: 透明アクリル (t3) / 半透明塩ビパンチング (t3) / **中空ポリカ (t4, 奥行筋)** / **ブラックマット地アクリル (t3)**
   - 補強あり時: 上部・下部を個別指定可能（透明アクリル / 半透明塩ビパンチング / **中空ポリカ (t4, 奥行筋)** / **ブラックマット地アクリル (t3)**）
4. **背面**: 透明アクリル (t3) / 半透明塩ビパンチング (t3) / **中空ポリカ (t4, 横筋)** / **ブラックマット地アクリル (t3)**
5. **天面**:
   - 1枚天板時 / 2分割時（左側・右側）を個別指定可能。
   - 選択可能素材: 透明アクリル、半透明塩ビパンチング、**金網（15mm目 / 25mm目 / 30mm目、線径φ3.2 SS400黒塗装）**。
6. **仕切り板（２室分けON時のみ表示）**:
   - **アクリル黒両面マット 3.0mm（標準）** / **透明アクリル 3.0mm** / **塩ビパンチングボード 透明 3.0mm（φ3.1-P7）** を選択可能。寸法は非表示。
- **中空ポリカ（ツインカーボ、厚み t=4mm）の仕様**:
  - **背面**: 横方向（左右水平方向・X軸方向）に筋が走る方向。
  - **側面**: 奥行方向（前後水平方向・Z軸方向）に筋が走る方向。
  - リブ隔壁の光沢ハイライト線とシャドウ境界線、セル内部の透過屈折グラデーション、およびバンプマップ（凹凸反射）により、**板を通した際のボケ感とリブ筋の立体的な陰影**をリアルに再現。
- **ブラックマット地アクリル（厚み t=3mm）の仕様**:
  - 光を通さない完全不透明、低グロスでシックなつや消しマットブラック（深みのある黒色、微細な陰影）仕上げ。床面・背面・側面に適用可能。
- **ブラックフレーム時の金網インナー構造**:
  - ブラックケージに金網を取り付ける場合、間口内にシルバーのインナーフレーム（`AFS-2020-5`）を自動構築し、実物写真通りの構造を精密再現。
  - **組立余裕寸法**: 奥行方向は外側間口より6mm減（例: 404mm）、幅方向は左右インナーフレーム内寸より6mm減（例: 664mm）として角突き当て部に各3mmの隙間を設け、手配型番を自動算出。
  - **金網寸法**: 外側ブラックフレーム間口より40mm小さくしてはめ込み10mmを足す（＝間口各辺から30mm減算）計算式を採用。750×450ケージ時は **680 × 380 mm**（型番: `FENP25-A680-B380`）で手配。
- **天面2分割・片側金網時のコンセント穴制御**:
  - 天面片側に金網が選ばれた場合、もう片側の塩ビパンチング天板には穴を開けず、背面からの配線に一本化。
  - 背面パネルのコンセント穴（φ30ゴムグロメット）を上部左右端の2箇所に自動制御し、BOM数量も2個に連動。

### 5. 耐震安全基準に基づく転倒注意喚起
- 家具の耐震安全基準（総務省消防庁等）に準拠した【 $B \div \sqrt{H}$ 】のリアルタイム計算ロジックを搭載。
  - **標準（ゴム脚）**: 安全目安ライン **【 3.8 】**
  - **キャスター仕様**: 支点狭まりを考慮した安全目安ライン **【 4.2 】**
- 基準値を下回った場合、プレビュー画面下に「⚠️ 転倒注意」警告バナーがリアルタイム表示されます。

### 6. こだわりの金物・パーツ再現
- **段付きローレットノブ（つまみネジ）**:
  - SUS303製 RNSFS4 準拠（外径φ16mm、ボス径φ8mm）。左右扉の端から15mm・上下中央に配置（合計2点）。
- **プッシュ式スライド扉鍵**:
  - C-108 ワンプッシュシリンダー錠（外径φ18.5mm、鍵穴スリット付）。右扉下端から約20mm位置に配置（1点）。
- **引き違いスライド扉 開閉操作**:
  - 「全閉」「▶ 左扉を開く」「◀ 右扉を開く」のスムーズアニメーション（3秒、easeInOutCubic）。
  - つまみ同士の干渉を防ぐため、端から20mm手前で自動停止する排他制御。
  - 扉の開閉操作を行っても、部材表（BOM）の数量が重複・増殖しない安全設計。

### 7. 溝なし補強フレーム（AFSF-2020-4）によるクリーン設計
ケージ室内側へのゴミ・床材・糞の侵入やホコリ溜まりを防止するため、分割補強箇所に**1面溝なしアルミフレーム（AFSF-2020-4）**を採用しています：
- **室内側への溝なし面配置**:
  - **床面中央補強フレーム (2分割時)**: **上面（+Y）**を溝なしフラット面に配置。床材や汚れの溝への入り込みを防止し、掃除が容易。
  - **天面中央補強フレーム (2分割時)**: **下面（-Y）**を溝なしフラット面に配置。見上げた際の美観向上とホコリ溜まり防止。
  - **側面補強フレーム (左右・2分割時)**: **内側面（左:+X / 右:-X）**を溝なしフラット面に配置。上下溝で側面板を保持しつつ室内側はフラット。
  - **正面中桟 (レール受け・Type C専用)**: **奥側（-Z）**を溝なしフラット面に配置。上面（ガラスレール載せ）および下面（前窓保持）の溝を維持しつつ室内側をクリーン化。
- **フレームカラー別の自動連動**:
  - **シルバーフレーム**: 3Dプレビューで室内側溝なしプロファイルを描画し、部材表（BOM）に **`AFSF-2020-4-{長さ}`** を自動出力。
  - **ブラックフレーム**: 溝なし規格が存在しないため、通常フレーム（4面溝あり）および通常型番 **`AFS-2020-4-BK-{長さ}`** を維持。
- **UI表示への配慮**: オプション設定画面には型番を出さず、ユーザーに分かりやすい現行の名称表記を維持。

### 8. 部材集計リスト（BOMテーブル）
- **メーカー手配用型番表記**:

## 💡【開発・AIメンテナンス専用設計メモ】見積もり計算のUX演出（Labor Illusion）

> [!NOTE]
> **AIアシスタントおよびメンテナー向け重要事項**
> 本シミュレーターの見積もり機能（`showEstimateCalculation` / `runStructuralAndCostSimulation`）には、**「あえて5〜10秒のランダムな待機時間とスピナーアニメーションを挟んでから金額・重量を表示する」**というUX演出（Labor Illusion / 努力の錯覚）が意図的に組み込まれています。

### 1. なぜあえて待たせるのか？
- ボタン押下後、一瞬で金額が出ると「簡易的で適当な計算しかしていないのではないか」という印象を与えてしまい、特注ケージの本格感・納得感が損なわれるためです。
- 先に枠を出現させ、価格・重量部分でくるくる回るスピナー（「部材積算中...」「重量計算中...」）を表示し、5〜10秒待たせることで「ミリ単位の寸法・フレーム切断ロス・アクリルたわみ応力などを厳密に計算している」という信頼感と価値をユーザーに提供します。

### 2. なぜ本格的なシミュレーションコードの体裁になっているのか？（からくり露見防止）
- お客様がブラウザの開発者ツール（F12）等でソースコードを閲覧した際、`// あえて待たせる` や `setTimeout(5000)` のような露骨なダミー待機コードがあると、からくりがばれて興ざめしてしまいます。
- そのため、`main.js` 上では **「多次元部材マトリクスと構造負荷の非同期計算パイプライン（`runStructuralAndCostSimulation`）」** として命名・実装されており、外部からは高度な非同期計算ステップを行っているように見える設計になっています。

### 3. AI自身が騙されないための注意
- **コード上は高度な非同期ループに見えますが、実際には意図的なUX演出ウェイトです。**
- AIが今後のリファクタリングやパフォーマンス改善を行う際、「この計算ループは重いから削除しよう」「即時計算に戻そう」と誤認してこの演出を消してしまわないよう注意してください。
